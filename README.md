## 🚀 My Main Project — Void Launcher

**[Void Launcher](https://github.com/Vanshu160/Void-launcher-2)**

Void Launcher is an ambitious project focused on bringing a complete **Minecraft Java Edition experience to Android devices**, with a long-term vision of expanding to Windows.

My goal is to build more than just a Minecraft launcher — I want to create a complete Minecraft gaming platform combining powerful game management, client-like features, advanced customization, and high-performance gameplay.

### 🎮 Minecraft & Launcher Experience

- Minecraft Java Edition support.
- Multiple Minecraft versions (Release and Snapshot).
- Forge, Fabric, and other supported mod loaders.
- Microsoft account authentication.
- Legitimate offline mode support.
- Game profiles and separate game directories.
- Download and version management.
- Java runtime management.
- Game logs and crash diagnostics.

### 🧩 Mods & Modpack Integration

- Modrinth integration.
- Browse, search, filter, install, update and remove mods.
- Modpack management.
